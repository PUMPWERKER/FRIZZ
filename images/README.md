The manual's diagrams and figures, drawn by [`firmware/tools/diagrams/diagrams.py`](../firmware/tools/diagrams/diagrams.py): to change one, edit that script and run it (Python 3, no packages), which rewrites every SVG here. The chapters' figures (`key-*`, `panel-*`, `keys-*`) take their colours from the firmware and the knobs' names from `MANUAL.md`, so run it again after changing either.
